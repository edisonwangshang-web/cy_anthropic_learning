# 决策记录

## D-001：通用判断力 + 一套固定实操工具

日期：2026-07-19  
状态：有效

课程主线教授可迁移的规格、验证、安全和运维判断，同时选择一套工具贯穿实操。原因是完全工具无关会让零基础学员难以落地，完全绑定工具又会缩短课程寿命。

## D-002：生产可用是主线，不是最后附加章节

日期：2026-07-19  
状态：有效

数据、权限、安全、部署、日志、监控、备份和回滚必须随着功能逐步进入课程。原因是 Demo 和生产产品的差异不是“功能更多”，而是系统能否可靠承担真实责任。

## D-003：文章必须课程化，不能只提供外链

日期：2026-07-19  
状态：有效

每篇必读文章需要绑定中文导读、关键观点、阅读问题、中文精读摘要、即时练习和项目产出。英文原文是核对证据的来源，不是零基础学员的默认阅读入口。

## D-004：进度按掌握证据计算

日期：2026-07-19  
状态：有效

打开链接或滚动页面不计为掌握。进度由文章导读确认、即时回忆、项目文件和最终验收组成。阶段批量完成按钮已移除，避免绕过学习检查。

## D-005：统一六步学习循环

日期：2026-07-19  
状态：已被 D-011 与 D-014 替代

采用“中文导读 → 中文精读摘要 → 必要时核对英文来源 → 即时回忆 → 完成示例 → 自己产出 → 验收”的阶段结构。

依据：

- Coursera：学习目标、教学材料和测评对齐。
- DataCamp：Assess、Learn、Practice、Apply 循环。
- Codecademy：从引导项目逐步过渡到低引导和独立项目。
- Khan Academy：用 Mastery 而不是浏览量表示进度。
- Duolingo：短单元、当前路径和间隔复习。
- freeCodeCamp：理论、Workshop、Lab、Review、Quiz 和认证项目组合。

## D-006：视觉接近 OpenAI 语言但不复制品牌

日期：2026-07-19  
状态：有效

使用白色背景、黑灰文字、细边框、浅灰表面、轻圆角和黑色主操作。不得使用 OpenAI Logo、官方品牌资产或造成官方产品误认的命名。

## D-007：保持本地静态单页

日期：2026-07-19  
状态：有效

课程页继续保持单文件 HTML，不依赖远程库。原因是当前交付方式需要直接打开、可离线阅读和低维护成本。未来若增加账号、云同步或教师端，再评估应用化。

## D-008：开课准备由课程提供，学员只负责确认

日期：2026-07-19  
状态：有效

零基础学员不应被要求自行设计学习目录、挑选练习项目或编写 AI 提示词。课程必须给出默认案例、可下载工作区、现成提示词和明确的逐步动作；学员完成确认后再进入正式学习。

## D-009：中文精读摘要是默认阅读入口

日期：2026-07-20  
状态：有效

课程中的 25 篇文章首先进入本地中文精读摘要，英文原站保留为完整论证、数字、方法、引用和细节核对入口。现有中文内容平均仅占英文原文很小一部分，因此必须明确标注为课程精读摘要，不能称为完整译文，也不能暗示覆盖了原文全部证据。

## D-010：课程内文章使用抽屉阅读

日期：2026-07-20  
状态：有效

从课程主线点击文章时，在右侧抽屉中加载单篇中文精读摘要，不离开当前阶段。关闭抽屉后恢复到触发链接并继续阅读问题、即时回忆和产出；完整摘要库仍作为独立检索入口保留。

## D-011：用认知科学重构学习循环

日期：2026-07-20  
状态：有效

每章固定采用“读前判断 → 5 个概念分块 → 带题阅读 → 即时回忆与反馈 → 完成示例 → 自我解释 → 项目迁移 → 间隔复习”。原因是零基础学习者的工作记忆有限，容易把熟悉感误判为掌握；课程必须主动降低无关认知负荷，并通过检索、生成、反馈和隔时复现建立长期记忆与迁移。

每篇必读文章的导读固定包含：阅读前判断、论证地图、生活类比、常见误区、读后自我解释。每章核心内容保持 3 至 6 项，当前统一为 5 项。

## D-012：工程博客路径定位为正式产品课的先修课

日期：2026-07-20  
状态：有效

六阶段页面只承诺训练工程判断、规格、工具、安全、评测和故障复盘，不再把完成工程判断包等同于完成生产产品。真实数据库、后端、客户端、权限、部署、监控、备份和恢复属于正式产品课的八个动手里程碑，必须以运行证据验收。

## D-013：学习材料的名称必须反映覆盖范围

日期：2026-07-20  
状态：有效

摘要、导读和完整翻译是不同内容类型。只要材料没有逐段覆盖完整论证，就统一称为“中文精读摘要”，并在阅读器、课程入口、分类报告和项目文档中说明证据核对边界。

## D-014：采用“示范、引导、独立、延迟复习”的渐隐支架

日期：2026-07-20  
状态：有效

每章固定采用：记录读前判断 → 概念分块 → 带题阅读 → 即时检索反馈 → 完成示例 → 补全引导练习 → 自我解释 → 独立迁移 → 量规验收 → 24 至 48 小时延迟复习。读前回答、引导练习、自我解释和延迟复习状态必须持久化；掌握不能只由单选题或浏览行为决定。
